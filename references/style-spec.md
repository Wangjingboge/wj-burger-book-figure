# 版式规格（style spec）

所有数值与 `scripts/wj_figure.py` 中的常量一一对应。改样式改脚本头部常量，不要在单张 config 里硬写颜色。

## 1. 画布与几何

| 项目 | 4:3 | 3:4 |
| --- | --- | --- |
| figsize / dpi | 12×9 @120 → 1440×1080 | 9×12 @120 → 1080×1440 |
| 绘图区 rect（figure 坐标） | `[0.083, 0.150, 0.834, 0.725]` | `[0.150, 0.398, 0.798, 0.452]` |
| 标题基线 y | 0.950（va=top） | 0.958 |
| 图例默认位置 | 图内左上 `in` | 图下方左对齐 `out-bottom` |

- 绘图区左边距 ≥0.08，给竖轴标签留位；下边距 ≥0.15，放"年份/持有年份"。
- 标题到绘图区顶端至少空出 0.10 的画布高度，否则显得顶。
- 3:4 竖版因为窄，图内图例容易压曲线，默认移到图下方；仍要放图内时，anchor 取 `[0.02, 0.92]` 并先确认该区域无曲线。

## 2. 色彩（纯黑白）

```
INK   #111111   主线、主文字、端点
BODY  #2b2b2b   轴标签、刻度数字
MUTED #4f4f4f   次要说明（如"相差"）
GRID  #c9c9c9   y 向网格
```

不用灰底、不用阴影、不用半透明填充。需要区分数据用**线型**（实线/虚线/点线）和标记填充（空心/实心），不用颜色。

## 3. 字体与字号

- 字体：华文宋体 `C:\Windows\Fonts\STSONG.TTF`；脚本按 `FONT_CANDIDATES` 顺序回退到中易宋体 / 宋体 / Noto Serif CJK。
- 全图一个字号：17pt（1440 宽画布）。3:4 画布可用 16–17pt。
- 标题**只加粗不放大**：`path_effects=[pe.withStroke(linewidth=0.95, foreground=INK)]`。宋体没有粗体字重，设 `fontweight="bold"` 会触发字体替换，字形会变。
- 中文与数字之间留半角空格：「沪深 300」「第 1 年」「2007 年 10 月」。

## 4. 坐标轴

- `spines`：隐藏 top/right；left/bottom 线宽 1.2、色 INK。
- 刻度：`direction="in"`、`length=5.5`、`width=1.0`、`pad=8`，标签色 BODY。
- 网格：仅 `ax.yaxis.grid`，`linestyle=(0,(1,4))`、`lw=0.8`、色 GRID，必须 `set_axisbelow(True)`。
- 刻度数量：4–6 个。x 轴年份按 4 年间隔（2008/2012/2016/2020/2024）比逐年更清爽。
- 轴标签 labelpad：y 16、x 10。

## 5. 曲线

| 类型 | lw | 说明 |
| --- | --- | --- |
| 主实线 | 1.8（长周期）/ 2.7（点少的对比图） | 点多时线细一点才不糊 |
| 虚线 | 1.5 / 2.1，`(0,(5,2.5))` | 长周期用 5,2.5；小图可 6,3 |
| 参考横线 | 1.5，`(0,(6,3))` | 成本线/目标线 |

- 端点标记：`ms=7`，`mew=1.5`。起点空心（白填充）、终点实心，是这套图的固定语汇。
- 对比图里所有点都画空心圆（`markers=all, marker_fill=hollow`）。
- `solid_capstyle="round"`。

## 6. 图例

- 不用 `ax.legend()`，手画线段 + 文字，避免自动布局把图例甩到图外或压住曲线。
- 图内：`anchor` 是 axes 分数坐标；`sample_len` 0.085–0.115；`row_gap` 0.05（长周期）～0.10（小图）。
- 图例文字本身就是序列说明，可以带结论：「实线：遭遇单次深度回撤的组合，年化 4.8%」。
- 文字起点 = 线段末端 + 0.022（axes 分数），`va="center"`。
- 放之前先看该区域有没有曲线/标注：左上被占用时换左下或右上，别无脑固定。

## 7. 数值标注

- 每个关键拐点标数值，保留与数据一致的小数位（100.00 / 143.75 / 4979.43）。
- 用 `ha`/`va` 精确控制八方向：峰顶标上方（`va=bottom`）、谷底标下方（`va=top`）、末端标右侧（`ha=left`）。
- 标注与线、网格线保持 ≥6px 视觉间距；贴线时挪方向，不要靠调字号解决。
- 终点差距用双向箭头 `<->`，`lw=1.1`，`shrinkA/B=0`，箭头右侧两行文字（"相差" / "37.09 万"）。

## 8. 质检清单

出图后逐条过：

- [ ] 画布尺寸 1440×1080 或 1080×1440，模式 RGBA
- [ ] 全图只有一个字号；标题是加粗不是放大
- [ ] 无图号、无副标题、无标题下横线、无重复单位
- [ ] 图例不压曲线、不压标注、不出绘图区
- [ ] 每个数值标注都没被线/网格穿过（放大 3–4 倍看）
- [ ] 首尾端点标记正确（起点空心、终点实心）
- [ ] 上、下、左、右留白大致均衡，没有一边贴边
- [ ] 图上每个数值与数据源逐个核对，跌幅是算出来的不是估的
- [ ] 同时产出 `_白底预览.png`

## 9. 踩坑记录

1. **透明底 + 黑字**：放在深色阅读器里会看不见，所以永远同时给白底预览，并在交付时说明用哪张。
2. **matplotlib 中文压线**：自动布局对中文标签不友好，一律手写坐标 + `ha/va`，然后裁剪放大验证。
3. **图例自动布局**：`fig.legend(loc="lower center")` 会和 x 轴标签抢位置，改手排。
4. **数据口径**：2021-02-18 沪深 300 盘中 5930.91 曾高于 2007 年盘中 5891.72，但当日收盘 5768，收盘价从未收复 2007-10-16 的 5877.20。凡涉及"从未回本"必须区分盘中/收盘。
5. **截止日漂移**：改图时容易只改标题没改数据末点，导致"截至 6 月"却用了 11 月点位。改口径要同时改 `points` 末点、`annotations` 数值、跌幅、标题措辞（18 年 8 个月就写"近 19 年"）。
